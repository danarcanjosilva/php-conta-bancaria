🏦 Sistema de Conta Bancária em PHP

Projeto desenvolvido em PHP com foco na aplicação prática dos conceitos de Programação Orientada a Objetos (POO).

A aplicação representa uma conta bancária por meio de uma classe, permitindo trabalhar com propriedades e métodos relacionados às operações de uma conta.

💻 Conceitos aplicados

O projeto foi desenvolvido para praticar fundamentos de Orientação a Objetos em PHP, incluindo:

Classes e objetos
Atributos e propriedades
Métodos
Encapsulamento
Construtores
Modificadores de acesso
Organização e reutilização de código
Modelagem de uma entidade do mundo real

🎯 Objetivo

O objetivo deste projeto é demonstrar a aplicação dos conceitos fundamentais de POO utilizando PHP, utilizando o exemplo de uma conta bancária para representar uma entidade e suas características dentro de uma aplicação.

Este projeto faz parte dos estudos e práticas de desenvolvimento utilizando PHP e Programação Orientada a Objetos.
